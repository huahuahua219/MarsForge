Abstract

Abstract

We present a procedural framework for generating photorealistic Mars-like terrains with multi-modal data outputs including RGB images, semantic masks, depth maps, and physically accurate USD assets. Our pipeline enables seamless integration with Isaac Sim for autonomous navigation research, supporting multiple path planning algorithms with realistic physics simulation.

Framework

Framework Overview

Our framework consists of three main modules: procedural terrain generation, multi-modal data synthesis, and physics-based asset export for simulation.

Pipeline

Pipeline Overview

Stage Description Output
A. Scene Generation Blender-based terrain & rock placement Batch scenes + masks
B. Physics Export USD with friction & collision Isaac-ready assets
C. Navigation Demo PhysX costmap + multi‑algorithm planning Trajectory visualizations
A

Scene Generation

Blender-based terrain & rock placement with semantic masks. Supports variable terrain complexity and rock distributions.

Output: batch scenes + RGB + semantic masks + depth
B

Physics Export

USD export with friction, collision, and inertial properties. Optimized for Isaac Sim's PhysX engine.

Output: Isaac-ready assets (.usd)
C

Navigation Demo

PhysX costmap generation + multi‑algorithm planning (A*, Dijkstra, RRT*, Theta*).

Output: trajectory visualizations + performance metrics
